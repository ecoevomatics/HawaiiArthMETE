# Analysis of arthropod communities in Hawaii using METE theory 

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20319088.svg)](https://doi.org/10.5281/zenodo.20319088)


Repo supporting the manuscript "A maximum entropy perspective reveals deviations from steady state during active diversification" which uses a data set of arthropod abundances and body sizes from Hawaiʻi to investigate if the geologic age of substrates influences community assembly through the lens of the Maximum Entropy Theory of Ecology.

Refer to the [manuscript supplement](inst/ms/hawaii-arth-mete-supp.pdf) for details on package installation and use.
